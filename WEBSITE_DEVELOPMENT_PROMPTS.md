# Parley Website Development Prompts

## 1. Full Product Audit and Improvement

Fix and improve the entire Parley website. Audit the UI, functionality, responsiveness, navigation, authentication flow, and user experience. Make it polished, intuitive, and production-ready.

## 2. Pricing and Negotiation Workspace Redesign

Redesign the Pricing Advisor and Negotiation pages as full-page workspaces with a clearer layout. Make inputs and results easy to understand, responsive, and visually consistent with the rest of the app.

## 3. Feature Expansion

Add useful, fully functional features that fit an AI pricing and negotiation copilot for freelancers and small businesses. Include a rate calculator, deal workspace, proposal builder, scope-change advisor, payment-terms planner, and negotiation trade-off tool where appropriate.

## 4. Dashboard and Navigation Improvements

Improve the dashboard and sidebar so the product feels guided and easy to use. Add clear navigation, contextual explanations or tooltips, account controls in a profile drop-up, and fix UI overflow, hydration, and authentication issues.
